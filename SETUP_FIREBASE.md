# Firebase Setup Guide for StudyMate Classroom

This guide provides the exact steps to configure Firebase Authentication and Cloud Firestore for the **StudyMate Classroom** Android project.

---

## Prerequisites
- A Google account.
- [Node.js](https://nodejs.org/) installed (for `npm`).
- Flutter SDK 3.47+ & Dart SDK 3.13+ added to your system `PATH`.
- Chrome or an Android device/emulator.

---

## Step 1: Create a Firebase Project
1. Navigate to the [Firebase Console](https://console.firebase.google.com/).
2. Click **"Add project"** or **"Create a project"**.
3. Name your project (e.g., `studymate-classroom`).
4. (Optional) Disable or enable Google Analytics, then click **"Create project"**.
5. Wait for the project creation to complete and click **"Continue"**.

---

## Step 2: Enable Email/Password Authentication
1. In the Firebase Console left navigation pane, select **Build > Authentication**.
2. Click **"Get started"**.
3. Under the **"Sign-in method"** tab, select **Email/Password**.
4. Toggle **Enable** for *Email/Password*.
5. (Leave *Email link / passwordless* disabled).
6. Click **Save**.

---

## Step 3: Create Cloud Firestore Database
1. In the left navigation pane, select **Build > Firestore Database**.
2. Click **"Create database"**.
3. Choose a Firestore location close to your users (e.g., `asia-south1` or `us-central1`).
4. Select **Start in production mode** (we will deploy strict security rules in Step 7).
5. Click **Create** and wait for the database provisioning to complete.

---

## Step 4: Install the Firebase CLI & FlutterFire CLI
Open your terminal (PowerShell or Bash) and execute:

```bash
# 1. Install Firebase Tools globally via npm
npm install -g firebase-tools

# 2. Login to your Google account with Firebase
firebase login

# 3. Activate FlutterFire CLI globally via Dart
dart pub global activate flutterfire_cli
```

*Note: Ensure your global pub cache bin directory (e.g., `%LOCALAPPDATA%\Pub\Cache\bin` on Windows or `~/.pub-cache/bin` on macOS/Linux) is in your system `PATH`.*

---

## Step 5: Configure FlutterFire in StudyMate Classroom
In your terminal, navigate to the project root directory and run:

```bash
flutterfire configure
```

1. Select your Firebase project created in Step 1.
2. Select the target platforms (ensure **Android** is checked).
3. Confirm when prompted to register the Android app.
4. FlutterFire will automatically generate `lib/firebase_options.dart` and download `android/app/google-services.json`.

---

## Step 6: Register Debug SHA-1 (Android)
If prompted or for debug validation:
1. In the terminal, run:
   ```bash
   cd android
   ./gradlew signingReport
   cd ..
   ```
2. Locate the `SHA-1` fingerprint under the `debug` variant.
3. In the Firebase Console, go to **Project Settings > General > Your apps > Android app**.
4. Click **"Add fingerprint"**, paste the SHA-1 value, and click **Save**.

---

## Step 7: Deploy Firestore Security Rules & Composite Indexes
The repository includes pre-configured security rules (`firestore.rules`) and index definitions (`firestore.indexes.json`).

Deploy them directly to your Firebase project:

```bash
# Deploy security rules and composite indexes
firebase deploy --only firestore:rules,firestore:indexes
```

### Security Rules Highlights
- **Classrooms**: `get` is allowed for any signed-in user (ensuring the join-by-code transaction can inspect current enrollments), while `list` is strictly limited to the classroom teacher and enrolled students.
- **Users**: Role must be `'Student'` or `'Teacher'` on creation and is immutable on update. Profile documents cannot be deleted.
- **Questions & Safe Seeding**: The global `questions` collection permits creation and editing strictly by teachers (`isTeacher()`) without any unauthenticated bypasses. Starter questions (20 questions across CS, Math, and Physics) are safely seeded when an authenticated teacher first accesses the Question Bank (or via `FirestoreService.instance.seedInitialQuestions(teacherId)`), guarded by `config/seed`.
- **Student Curriculum & Practicals**: Questions imported from `questions.json` in a student's ZIP archive are stored under `users/{uid}/subjects/{subjectId}/units/{unitId}/questions`, guaranteeing student ownership and privacy.

---

## Step 8: Verify and Run the App
Once `firebase_options.dart` has been generated by FlutterFire:
```bash
# Run static analysis
flutter analyze

# Execute all automated tests
flutter test

# Run the app on an emulator or connected phone
flutter run
```

If Firebase has not been configured yet, the app safely launches into an informative configuration error screen rather than crashing.
